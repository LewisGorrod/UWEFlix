# UWEFlix Version 6

Code for the UWEFlix web app.

## How to Run:

1. Download UWEFlixWeb to local machine
2. Install Django
3. Install Pillow (via 'pip install Pillow')
4. Navigate to UWEFlixWeb and run 'python manage.py runserver'
5. Visit 127.0.0.1:8000
